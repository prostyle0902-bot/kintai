# Airレジ 月次売上レポート

Airレジからダウンロードした「日別売上」CSVを読み込んで、月次の集計をコンソールとHTMLで出力します。
毎月の売上レビュー（店舗別・曜日別・前月比・決済構成・臨時休業の機会損失）を手作業なしで作るためのものです。

> **スマホで見たい場合は [`gas/`](gas/) を使ってください。**
> Googleドライブのフォルダを見て自動でレポートを作るGoogle Apps Script版です。
> パソコンでコマンドを打つ必要がなく、毎月1日にメールも届きます。集計の中身はこのPython版と同じです。

## 毎月の手順

1. **Airレジ管理画面 → 売上 → 日別売上** で対象月を指定し、店舗ごとにCSVをダウンロードする
2. 1か月分のCSVを1つのフォルダにまとめる（例 `~/airregi/2026-07/`）
   - **店舗名はファイル名から取ります。** `タコハイ7月.csv` → `タコハイ`。末尾の「7月」「2026-07」「2026年7月」は自動で落とします
3. 実行する

```bash
python3 tools/airregi/report.py ~/airregi/2026-07 \
        --prev ~/airregi/2026-06 \
        --out ~/airregi/2026-07.html
```

- `--prev` … 前月のフォルダ。指定すると前月比と「増減の内訳（組数要因／単価要因）」が出ます
- `--out` … HTMLの出力先。省略するとコンソール出力だけ
- 追加のインストールは不要（Python 3.9以降の標準ライブラリのみ）。HTMLも外部ファイルを読まないので、そのままメールやチャットで配れます

## 出力

```
■ 2026-07 合計 ¥4,975,190 / 2,368組 / 組単価 ¥2,101
  前月比 128%（組数増   ¥1,336,147 ／ 単価変動    −¥245,927）

店舗                         売上    前月比   営業       日商    組数     組単価   点/組   CL率    人数入力
------------------------------------------------------------------------------------
りゅうちゃん              1,983,030   133%   26   76,270   872   2,274   4.0   38%     58%
...
```

HTMLには次のセクションが入ります。

| セクション | 内容 |
| --- | --- |
| KPI | 売上・組数・組単価・キャッシュレス比率（前月比つき） |
| 前月からの増減の内訳 | 増減額を「組数が増えたぶん」と「単価が動いたぶん」に分解 |
| 店舗別 | 売上・日商・組単価・1組点数・キャッシュレス比率・人数入力率 |
| 曜日別 | 1営業日あたり売上と、最強／最弱曜日の倍率 |
| 日別推移 | 店舗ごとの日別バー（土日を濃色）。バーにカーソルを合わせると金額 |
| 臨時休業と機会損失 | 他店が営業していた日に休んだ日を拾い、同曜日平均で損失を試算 |

## 数字の読み方（重要）

- **「組数」は会計件数**です。Airレジの「客数」は会計時の人数手入力なので、入力が漏れると実際より小さく出ます。
  そのため本ツールは組数を基準にし、**組単価＝1会計あたりの金額**として表示します。
- **人数入力率＝客数 ÷ 組数**。100%を下回っている店舗は、人数入力が漏れている会計があるということです。
  ここが100%に近づくと、はじめて「1人あたりの客単価」で比較できるようになります。
- **機会損失は目安**です。「他店が営業していた日に休んでいた日」を臨時休業とみなし、その店の同曜日平均を積み上げています。
  全店が休む定休日（例：水曜）は対象外になります。
- 金額はすべて税込・値引後。返品・返金は差し引いていません。

## CSVの形式について

Airレジのエクスポートは店舗の設定（登録している決済手段・部門）によって**列数が変わります**。
列の位置ではなくヘッダー名で必要な列（集計日／売上／客数／組数／商品点数／現金売上高／その他売上高／値引額）を
引き当てているため、決済手段が多い店舗と少ない店舗が混在していても同じように読めます。
文字コードは Shift-JIS（cp932）・UTF-8 のどちらでも構いません。
