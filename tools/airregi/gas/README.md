# スマホで見る売上レポート（設置のしかた）

Googleドライブの「Airレジ売上CSV」フォルダにCSVを入れておくだけで、
スマホで売上レポートが見られるようになります。毎月1日の朝には、まとまった売上がメールで届きます。

設置は最初の1回だけ。**20分ほど**で終わります。パソコンでやってください。

---

## 用意するもの

- Googleドライブの「**Airレジ売上CSV**」フォルダ（もうあります）
- この `Code.gs` というファイルの中身

---

## 手順

### 1. Apps Script を開く

パソコンのブラウザで **https://script.google.com** を開き、左上の「**新しいプロジェクト**」をクリックします。

> 勤怠アプリを作ったときと同じ画面です。

### 2. コードを貼り付ける

画面の中央に `function myFunction() {}` と書かれた枠があります。

1. その枠の中を**全部消します**（クリックして Ctrl+A → Delete。Macは ⌘+A → Delete）
2. この `Code.gs` の中身を**全部コピーして貼り付けます**
3. 左上の**保存アイコン**（フロッピーの絵）を押します

### 3. 動くか試す

画面の上のほうに「**関数を選択**」というプルダウンがあります。

1. そこから `testRun` を選びます
2. 隣の「**実行**」を押します
3. **初回だけ**「承認が必要です」と出ます → 「権限を確認」→ 自分のGoogleアカウントを選択
   → 「このアプリはGoogleで確認されていません」と出たら、**左下の「詳細」→「（プロジェクト名）に移動」** → 「許可」

   > 自分で作ったプログラムなので問題ありません。ドライブのCSVを読むための許可です。
4. 下に「実行ログ」が出て、こんな表示が出れば成功です

   ```
   見つかった月: 2026-07, 2026-06
   見つかった店舗: タコハイ, もも焼きJAPAN, ハナ, りゅうちゃん
   2026-07 合計 ¥4,975,190 / 2368組 / 組単価 ¥2,101
   ```

### 4. スマホで見られるようにする

1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 左の歯車マーク⚙をクリックして「**ウェブアプリ**」を選ぶ
3. 設定を次のようにします
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**（他の人にも見せたいなら「全員」）
4. 「**デプロイ**」を押す
5. **ウェブアプリのURL**が出ます。これをコピーしてスマホに送ってください
   （自分あてにLINEやメールで送るのが早いです）
6. スマホでそのURLを開き、**ホーム画面に追加**しておくとアプリのように使えます
   - iPhone：共有ボタン → 「ホーム画面に追加」
   - Android：メニュー → 「ホーム画面に追加」

### 5. 毎月メールが届くようにする

1. 「関数を選択」から `setupMonthlyTrigger` を選ぶ
2. 「実行」を押す（1回だけでOK）

これで毎月1日の朝9時に、前月の売上がメールで届きます。

---

## 毎月やること

**エアレジからCSVをダウンロードして、「Airレジ売上CSV」フォルダに入れるだけ。**

1. Airレジ管理画面 → 売上 → 日別売上 → 月を選んでCSVをダウンロード（店舗ごと）
2. そのファイルをGoogleドライブの「Airレジ売上CSV」フォルダに入れる
3. スマホでURLを開く → もう新しい月が表示されています

前の月のファイルは**消さずにそのまま残しておいてください**。残っていると「前月比」が出ます。
（ファイル名は「タコハイ7月.csv」のように、店名＋月 の形にしておくと店舗名がきれいに出ます）

## 画面の見かた

| 表示 | 意味 |
| --- | --- |
| 売上合計 | その月の全店合計。下に前月比 |
| 組数 | 会計の件数（レシートの枚数） |
| 組単価 | 1回の会計あたりの平均金額 |
| 前月からの増減 | 増減を「お客さんの数が変わったぶん」と「単価が変わったぶん」に分けたもの |
| 日商 | 1営業日あたりの売上 |
| 1組の品数 | 1回の会計で頼まれた商品の数 |
| 棒グラフ | 日ごとの売上。濃い色が土日 |
| 臨時休業 | 他店が開けていた日に休んだぶんの、おおよその売上ロス |
| 人数入力◯% | 会計のときに人数を入れた割合。100%でないと「1人あたりの単価」は出せません |

上のほうにある「26/07」「26/06」のボタンで**月を切り替え**られます。

## うまくいかないとき

**「フォルダ『Airレジ売上CSV』が見つかりません」と出る**

フォルダ名が違うかもしれません。コードの上のほうにある

```javascript
var FOLDER_NAME = 'Airレジ売上CSV';
```

の `'　'` の中を、実際のフォルダ名に書き換えて保存してください。
それでもダメなら、ドライブでそのフォルダを開いたときのURL

```
https://drive.google.com/drive/folders/15YGUIu3to3jfg...
                                        ↑この部分をコピー
```

を、コードの `var FOLDER_ID = '';` の `''` の中に貼り付けます。

**店舗名が「タコハイ7月」のように月まで付いて表示される**

ファイル名の付け方が想定と少し違うだけです。そのままでも数字は正しいので気にしなくて大丈夫です。
気になる場合はドライブでファイル名を「タコハイ7月.csv」の形に直してください。

**特定の店を表示したくない**

コードの `var EXCLUDE = [];` を、たとえばこう書き換えます。

```javascript
var EXCLUDE = ['十三里屋'];
```

**コードを直したのに画面が変わらない**

コードを変更したら、もう一度「デプロイ」→「**デプロイを管理**」→ 鉛筆マーク →
バージョンを「**新バージョン**」にして「デプロイ」を押してください。URLは変わりません。

## 補足

- 金額はすべて税込・値引後です
- 「客数」ではなく「組数（会計件数）」を基準にしています。Airレジの客数は会計時の手入力なので、
  入れ忘れがあると実際より少なく出るためです
- 臨時休業の金額はあくまで**目安**です（その店の同じ曜日の平均から計算しています）
- パソコンで使いたい場合は、ひとつ上のフォルダにある Python版（`report.py`）も同じ集計ができます
