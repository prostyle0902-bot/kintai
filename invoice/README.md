# 月次請求書の自動作成・送信（大衆酒場りゅうちゃん／河野竜二）

大衆酒場りゅうちゃん 店長・河野竜二氏（個人事業主）への業務委託料（月額 300,000円・税込）について、
毎月月末に請求書PDFを作成し、経理メール（seikyu@prostyle-co.com）へ送信するための仕組み。

## ファイル構成

- `config.json` — 発行者・宛先・金額・送信先などの設定。金額や名義の変更はここを編集する。
- `template.html` — 請求書のレイアウト（A4・1ページ）。
- `generate_invoice.py` — テンプレートに値を差し込み、ヘッドレスChromiumでPDF化するスクリプト。
- `output/` — 生成されたPDFの出力先（Git管理外）。

## 使い方

```bash
# 当月（JST）分を生成
python3 invoice/generate_invoice.py

# 年月を指定して生成
python3 invoice/generate_invoice.py --year 2026 --month 8
# → invoice/output/seikyusho_202608_kono.pdf
```

## 自動実行

Claude Code のスケジュールタスク（Routine）が毎月28〜31日の17:00（JST）に起動し、
その日がJSTで月の最終日の場合のみ、当月分の請求書PDFを生成して
seikyu@prostyle-co.com へメール送信する（それ以外の日は何もしない）。

## 経理上の注意

- 河野氏は適格請求書発行事業者（インボイス）の登録を行っていないため、本請求書は適格請求書に
  該当しない。仕入税額控除は経過措置（2026年9月30日まで80%、以降2029年9月30日まで50%）の対象。
- 本書は支払側（Prostyle株式会社）で作成する書類のため、実務上は仕入明細書（自己発行）に近い。
  請求書面にもその旨を記載しており、河野氏本人に内容の確認（承諾）を得ておくことが望ましい。
